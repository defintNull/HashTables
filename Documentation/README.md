# Hashtable Testing Documentation

La cartella contiene l'ambiente per la scrittura e la compilazione della documentazione tramite LaTeX.

---

## Struttura della cartella

    .
    ├── appendix/        # Appendice
    │
    ├── bibliography/    # Bibliografia
    │
    ├── build/           # Output della compilazione
    │
    ├── chapters/        # Capitoli
    │
    ├── frontmatter/     # Copertina e pagine iniziali
    │
    ├── images/          # Immagini
    │
    ├── main.tex         # File principale
    │
    ├── preamble.tex     # Configurazione pacchetti e dipendenze
    │
    └── README.md

---

## Utilizzo

La relazione completa del progetto è disponibile al seguente percorso:
Documentation/build/main.pdf

Per ricompilare la relazione è necessario avere installato sul proprio sistema un compilatore LaTeX con i pacchetti di base.

È possibile procedere alla compilazione:
- manualmente (es. pdflatex, bibtex, ecc.)
- oppure tramite l'estensione LaTeX di VS Code
