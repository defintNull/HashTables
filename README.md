# Hashtable Testing

Il progetto ha l'obiettivo di proporre un'implementazione in C++ delle hashtable, verificarne la correttezza e analizzare diverse tecniche di:
- gestione delle collisioni
- ridimensionamento (resize)
- gestione del max_load_factor
